# Risk Register

This document tracks project risks identified during meetings and planning sessions.

| ID | Risk Description | Mitigation |
|----|------------------|------------|
| 1 | Team members lack oncology/urology expertise | Consult domain experts, validate findings with literature |
| 2 | Symptoms definition too broad (e.g. "lower-abdomen pain") | Refine symptom list, document assumptions, iterate with clinical input |
| 3 | Dataset limited to two hospitals | Note limitations clearly in reports; seek external data if feasible later |
| 4 | Potential misdiagnosis patterns leading to legal risk | Focus on descriptive analysis, avoid causal claims; include disclaimers |
| 5 | Time/budget constraints for retraining staff | Manage stakeholder expectations; prioritize high-impact actionable insights |

*Last updated: March 6, 2026*
